# WTDSight App

**WTDSight App** — это десктопная версия [WTDSight](https://dimas70800.github.io/WTDSight/), удобного онлайн-редактора для создания пользовательских прицелов `.blk` для War Thunder. Позволяет рисовать и сохранять прицелы локально, с прямым экспортом в папку игры.

## Возможности

- Инструменты рисования: линии, четырёхугольники, кривые, кисть, штриховка, заливка, произвольные фигуры, текст
- Векторизация (бета) — перевод загруженного изображения в линии или четырёхугольники
- Референс-изображение по URL или из файла — с настройкой размера, поворота, смещения и прозрачности поверх рисунка
- Выделение и редактирование объектов на холсте, зеркальное отражение, трансформация
- Загрузка прицела из файла или из `.blk`, экспорт как `.blk` или `.txt`
- Предпросмотр прицела на игровых фонах с разными цветами прицела
- Выбор папки с игрой в настройках — для автоматического сохранения экспортированного `.blk` прямо в неё
- Смена темы интерфейса и языка (русский/английский)
- Автоматическая проверка обновлений прямо в приложении

## Что здесь нового

- Добавлена возможность выбрать папку с игрой в настройках — для автоматического сохранения экспорта файла `.blk` в неё

## Системные требования

- ОС: Windows 10/11, macOS 11+, Linux x64
- ОЗУ: 2+ ГБ
- Места на диске: 400+ Мб
